KGPC Documentation
==================

KGPC is the Kreijstal Gwinn Pascal Compiler: a fork of Damon Gwinn's
Pascal-Compiler that has been extended to compile a substantial subset of
Free Pascal and to bootstrap FPC itself (`see STATUS <../STATUS.html>`_).

This site collects the project's hand-written design notes and the C API
surface that Hawkmoth extracts from the source.
